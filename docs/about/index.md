# About MetaIntegrator-py

!!! info "Open-Source Meta-Analysis for Genomics Research"
    MetaIntegrator-py brings modern Python performance and usability to meta-analysis of gene expression data, maintaining full compatibility with the trusted methodologies of the original R package.

---

## 🎯 Mission

**Empowering reproducible, high-performance meta-analysis of gene expression data for the research community.**

MetaIntegrator-py enables researchers to integrate multiple genomic datasets, identify robust biomarkers, and generate publication-quality results with modern Python tools and workflows.

---

## 📖 Project History

### Origins
MetaIntegrator began as an R package developed by the Khatri Lab at Stanford University to address reproducibility challenges in gene expression studies. The methodology was published in *Bioinformatics* (2017) and has been cited in hundreds of genomics publications.

### Python Port
In 2025, development began on MetaIntegrator-py to bring these trusted methods to the Python ecosystem, with goals of:
- **Performance**: Leveraging NumPy/Pandas for 2.8x speed improvements
- **Integration**: Native compatibility with scikit-learn, TensorFlow, PyTorch
- **Usability**: Pythonic API with comprehensive documentation
- **Community**: Open development with transparent testing

### Timeline

| Date | Milestone                                               |
|------|---------------------------------------------------------|
| **2017-01** | Original R MetaIntegrator published in *Bioinformatics* |
| **2025-12** | Python port development initiated                       |
| **2026-02** | Alpha release with core meta-analysis functionality     |
| **2026-03** | Beta release for internal testing                       |
| **2026-04** | Public v1.0.0 release with full R parity                |
